Trica Neon

A geometric typeface drawn with a single, even stroke, like a line of neon tube. The design grows from one module, a pill as wide as the capital height and half as tall; outer corners are rounded and inner joints stay sharp.

Use it

On your computer: download the zip of the latest release and install the fonts in fonts/otf (or the variable font in fonts/variable).

On the web: host the WOFF2 file of the variable font from fonts/webfonts; one file covers every weight.

@font-face {
  font-family: "Trica Neon";
  src: url("TricaNeon[wght].woff2") format("woff2");
  font-weight: 100 600;
  font-display: swap;
}
body {
  font-family: "Trica Neon", sans-serif;
}
